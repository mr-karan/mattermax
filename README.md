# Mattermax

Mattermax is a community-maintained, fully open source fork of
[Mattermost](https://github.com/mattermost/mattermost). It is not affiliated
with or endorsed by Mattermost, Inc.

Builds are Team Edition only and never include Mattermost's enterprise code.

## Quick start

Needs `just`, git, bash and Python 3; `just build` also needs the Go and Node
versions upstream pins.

See [docs/development.md](docs/development.md) to set up a machine, develop
and run Mattermax locally, and [docs/workflow.md](docs/workflow.md) for the
full workflow: patches, branding, releases and upstream upgrades. Agents: see [AGENTS.md](AGENTS.md).
